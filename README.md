# Sanal Salon

Evin 3D sanal kopyası. Tarayıcıda çalışan tek dosyalık Three.js sayfası: oda ölçüleri (düzenlenebilir kroki), eşyalar (Meshy GLB'leri), ışık modları ve boya/badana mockup'ı.

```
python3 build.py              # dist/sanal-salon.html (yayın)
python3 build.py --local-three  # dist/dev.html (test, three'yi node_modules'tan alır)
```

Ayrıntılar ve çalışma kuralları için `CLAUDE.md`, model küçültme için `tools/README.md`.
